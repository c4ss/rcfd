# ADR 0008: Multiple reference frame (frozen rotor) zones in the steady incompressible SIMPLE kernel

Status: accepted. The formulation, the validation checks and every limit below were written before any MRF code was
compiled or run. Roadmap items F-031 (MRF part of the partial scope) and F-114 (the interface is the planar
non-conformal join of `rcfd-mesh::non_conformal`).

## Decision

Absolute-velocity formulation (the form of the usual MRF implementations; derived here from the Navier-Stokes equations, no
vendor documentation consulted). In a cell zone that rotates with angular velocity `Omega` about an
axis `(origin, axis)` the solved variable is the absolute velocity `u`; the zone's frame velocity is
`u_f(r) = Omega x (r - origin)`. The momentum equation of the zone is

    div(phi_rel u) + Omega x u = -grad p + div(nu grad u) + ...,    phi_rel = phi - (u_f . S)_face,

with `phi` the absolute volume flux (the one that satisfies continuity and that the pressure equation corrects).
Derivation: `div(u (x) u) = div((u - u_f) (x) u) + div(u_f (x) u)` and `div(u_f (x) u) = (u_f . grad) u` (since
`div u_f = 0`), which equals `Omega x u` for an axisymmetric field `u` and is `Omega x u + O(non-axisymmetric part)`
otherwise; this is the frozen-rotor approximation: the flow outside the zone sees the zone's fields at the current
position of the rotor, no unsteady rotor/stator interaction.

* `phi_rel` replaces `phi` only in the convection matrix of the momentum equation; the pressure equation, the
  continuity measure, reports and the flux correction use `phi`. The offset `u_f . S` is a geometric constant per
  face, applied to faces whose two cells are both in the zone.
* `Omega x u` is a lagged explicit acceleration `-Omega x u` (cell value from the previous iterate, face value from the
  linearly interpolated/boundary velocity) added through the existing balanced-force `BodyForce` path, like the
  Coriolis term of the relative-velocity `rotating_frame` source.
* Frozen-rotor interface: the interface between an MRF zone and the rest is a face set across which the absolute
  velocity is continuous; since `phi_rel = phi` on interface faces (no offset), the momentum convected across it is the
  absolute momentum, i.e. the absolute/relative conversion of the frozen-rotor interface is the identity in the absolute
  formulation. The zone boundary must be a surface of revolution about the rotation axis so that the offset
  `u_f . S` vanishes there and `div(phi_rel)` stays zero in every cell: this is checked and a violation is a located
  validation error. The interface mesh is an ordinary internal face set; non-conformal interfaces come from the F-114
  join (planar interface perpendicular to the axis in this version).
* Boundary faces: wall/inlet/outlet/symmetry conditions are in the absolute frame (a wall that rotates with the zone
  is given the velocity `Omega x r` by an expression). Boundary faces of the zone get no offset and must also be
  surfaces of revolution (same check).
* Scope: steady `simple`/`simplec`, one or several MRF zones with disjoint cells, combinable with the other sources
  except `rotating_frame` in overlapping cells. Not included: transient (sliding mesh), PISO/PIMPLE, turbulence
  models and energy with an MRF zone are not forbidden but not validated, curved (cylindrical) non-conformal interfaces
  (the join of F-114 is planar), pseudo-transient time steps (they use `phi`, not `phi_rel`; documented).

New schema: `sources.<name>.type = "mrf"` with `zone`, `rotation_origin`, `rotation_axis`, `angular_velocity`; mesh
generators `annulus_3d` and `annulus_3d_interface` (new mesh fields `nz`, `nz_right`, `lz`, reusing `r_in`, `r_out`,
`nx` = cells around, `ny`/`ny_right` = radial cells).

## Pre-registered checks and limits (not changed after a run; a miss becomes an `#[ignore]`d `*_known_miss` test)

Common set-up: annulus `r_i = 0.5`, `r_o = 1.0`, kinematic viscosity `nu = 0.1`, `rho = 1`, `nx = 48` cells around,
SIMPLEC, `linear_upwind` convection, `non_orthogonal_correctors = 1`, pressure reference cell 0, tolerances
`tolerance_u = tolerance_p = 1e-10` or 4000 iterations, convergence reported. Inner wall `fixed` with the velocity
expression `(-w y, w x, 0)`, end planes `zmin`/`zmax` `symmetry` unless stated. Taylor-Couette: inner cylinder angular
velocity `W_i = 1`, outer fixed; analytic `u_theta = A r + B/r`, `A = -W_i r_i^2/(r_o^2 - r_i^2) = -1/3`,
`B = W_i r_i^2 r_o^2/(r_o^2 - r_i^2) = 1/3`, torque of the fluid on the inner cylinder per unit height
`4 pi rho nu W_i r_i^2 r_o^2/(r_o^2 - r_i^2) = 0.41888` (magnitude). Velocity scales: `V_i = W_i r_i = 0.5`.
Mesh counts are `(ny radial, nz axial)`; the height is `lz = 0.4` (two blocks of 0.2 for interface meshes).

* **(M1) Solid-body rotation exactness.** `W = 2` rad/s, `u = W x r` imposed on the inner and outer cylinder, end
  planes symmetry, fluid started at rest. Interface mesh `annulus_3d_interface`: lower block 8 x 3, upper block 11 x 4
  cells, MRF zone (`Omega = 2`) the lower block (`zone = box`, `z < 0.2`), no source in the upper block. Criteria:
  `max |u - W x r| / (W r_o) <= 2e-2` over all cells, and the pressure differences to cell 0 against `W^2 (r^2 - r_0^2)/2`
  within `5 %` of the range `W^2 (r_o^2 - r_i^2)/2`.
* **(M2) Taylor-Couette with an MRF zone.** Single block 16 x 2, MRF zone `zone = all` with `Omega = W_i`. Criteria:
  `max |u_theta - analytic| <= 1.5 %` of `V_i`; the torque from the `moment` report of patch `inner` within `3 %` of
  the analytic value.
* **(M3) Frame invariance.** The same flow computed (a) in the stationary frame (no source), (b) with MRF at
  `Omega = 0.5 W_i`, (c) at `Omega = W_i`, (d) at `Omega = 2 W_i`. Criteria: each of (a)-(d) obeys the M2 velocity (1.5 %
  of `V_i`) and torque (3 %) limits; the maximum cell velocity difference of (b), (c), (d) to (a) is `<= 1 %` of `V_i`;
  the spurious radial/axial speed `max(|u_r|, |u_z|)` is `<= 1e-3 V_i` in each run.
* **(M4) Taylor-Couette across a non-conformal interface.** `annulus_3d_interface`, lower block 16 x 2 (MRF,
  `Omega = W_i`), upper block 11 x 3 (stationary frame), 48 cells around in both. Criteria: `max |u_theta - analytic|`
  `<= 2 %` of `V_i` in both blocks; torque on `inner` within `3 %`.
* **(M5) Conservation across the interface (in the M4 run).** Converged to the residual targets above: maximum cell
  continuity imbalance (the `continuity` monitor, normalised by the largest face area times unit velocity) `<= 1e-8`;
  net volume flux through the interface faces `<= 1e-8 V_i A_if`; sum of the absolute interface fluxes
  `<= 1e-3 V_i A_if` (no spurious axial flow; `A_if` the interface area).
* **(M6) Through-flow across the interface.** `annulus_3d_interface` (lower 8 x 3, upper 11 x 4, `lz = 0.8`), inlet
  `zmin` uniform `u = (0, 0, 1)`, outlet `zmax` zero-gradient velocity and fixed pressure, walls `inner`/`outer` at rest
  (no-slip), lower block MRF with `Omega = 5`; reference run identical without the source. Criteria: |inflow| = |outflow|
  within `1e-9` relative; |interface flux| equals |inflow| within `1e-9` relative; `max |u_theta| <= 2 %` of the mean axial
  speed (1); `max |u_z - u_z(reference)| <= 2 %` of 1.
* **(M7) Validation.** Located errors (path `sources.<name>...`): zero rotation axis; non-finite angular velocity;
  zone with no cells; MRF boundary not a surface of revolution; MRF and `rotating_frame` in common cells; unsupported
  algorithm; invalid generator counts. Each has a test.
* **(M8) No regression.** `crates/rcfd-api/tests/baseline_hashes.rs` unchanged and passing (the kernel offset is
  `None` unless an MRF source is configured); `rotating_channel` remains the one registered known difference.

Limits (declared, not tested): frozen-rotor treatment of non-axisymmetric flows is the usual MRF approximation and is
not validated against any pump or turbine data (no such benchmark is claimed); only planar interfaces perpendicular to
the axis; the lagged `Omega x u` source limits robustness at high `Omega` relative to the viscous/convective rates
(the `Omega = 2 W_i` case is part of M3 for that reason).
