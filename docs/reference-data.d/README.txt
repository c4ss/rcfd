docs/reference-data.md is generated from the files *.part of this folder, joined in name order
(python scripts/process_report.py --write). 0000-base.part is the page as it stood on 2026-11-18.
An item adds its reference values as one new file <ADR number>-<item>.part (markdown; links are
relative to docs/) and never edits the page or another item's fragment (agent rules, rule 4).
