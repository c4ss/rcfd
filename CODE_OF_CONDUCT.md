# Code of conduct

rcfd follows the spirit of the Contributor Covenant, version 2.1. In short:

* Be respectful and constructive in issues, pull requests and reviews. Criticise work, not people.
* No harassment, insults, personal attacks, or sexualised language or imagery, in public or in private.
* Do not publish anyone's private information without their permission.
* Assume good faith, and accept that maintainers may edit, hide or remove contributions that break these rules.

These rules apply in every project space and when you represent the project elsewhere. Report a problem privately to the
maintainer through GitHub (a private vulnerability report reaches the maintainer if no other private channel is listed).
Reports are handled confidentially. A maintainer may warn, suspend or ban anyone who breaks these rules.
