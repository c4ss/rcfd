# Getting help

* **Something does not work as documented:** open an issue with the bug report template.
* **A question about using rcfd:** open an issue with the question template. Say what you tried and which page you read; the
  [documentation home](docs/index.md) and the [glossary](docs/glossary.md) may answer it first.
* **An idea or a missing capability:** open an issue with the feature request template.
* **A security problem:** do not open an issue; follow [SECURITY.md](SECURITY.md).
