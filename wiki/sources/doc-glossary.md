# Glossary

**Origin:** [docs/glossary.md](../../docs/glossary.md) at `origin/main` 2e94e5ef
**Kind:** reference page (also served by `rcfd help glossary`, ADR 0730)

## Summary

The project's own terms as other pages and the Studio's explanations use them. General CFD terms are deliberately not listed.

## Key points

- Process terms: [[adr]], [[f-item]], [[roadmap-status]] (done / PARTIAL / not started), [[wave]], [[gate]], [[registered-limit]], [[known-miss]] (and MISSED), [[unverified]], [[clean-room]], [[provenance]], [[bit-identical]].
- Case terms: [[case-file]], [[benchmark-descriptor]], [[template]], [[report]].
- Physics/case terms: [[mrf]], [[fan-01]], lid-driven cavity (the quick-start case and template `lid_driven_cavity`).
- Run terms: [[run]] (with queued, running, iteration, converged), runner ([[rcfd-runner]]), [[field-store]] (field, snapshot, field view).
- Interfaces: [[mcp]], [[studio]].
- 'Converged' means residual targets met: the calculation stopped changing, not that the answer is right.
