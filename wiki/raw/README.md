# raw/

Immutable source documents: clipped articles, papers, datasheets, transcripts, notes.
The LLM reads these and never edits, renames, or deletes them.

- Images and attachments go in `assets/` (Obsidian's attachment folder is set to it).
- Repo files (`../../docs`, ADRs, code) are sources too; reference them by path, don't copy them here.
- Respect licenses: don't add material that can't live in a public repo. Proprietary data stays out.
